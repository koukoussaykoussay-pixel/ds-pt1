# Python Task Manager

A simple console application for managing daily tasks.

## Features

- Add tasks with a non-empty title
- Display all tasks with their numbers
- Search task titles by keyword (case-insensitive)
- Display a message when there are no tasks or no search matches
- Exit the program from the menu

## How to run

1. Open this project folder in Visual Studio Code.
2. Open `main.py`.
3. Select **Run Python File** in the top-right corner.
4. Use the menu shown in the terminal.
